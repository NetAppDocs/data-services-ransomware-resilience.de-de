Wenn Sie die Benutzeraktivitätserkennung in Ransomware Resilience aktivieren, werden die aktuell in Console gespeicherten Anmeldeinformationen zum Managen Ihrer Datensammler verwendet. Falls Sie die Benutzeraktivitätserkennung zuvor über Data Infrastructure Insights (DII) Workload Security aktiviert haben, ersetzen die Anmeldeinformationen von Console die Anmeldeinformationen, die Sie zuvor in DII zum Managen von Datensammlern verwendet haben.
