= Entdecken Sie Workloads in NetApp Ransomware Resilience
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Bevor Sie Workloads schützen können, muss NetApp Ransomware Resilience diese erkennen, indem Volumes und Dateien in Systemen über Console-Agenten und Projekte in Ihrer Organisation analysiert werden.

Im Discovery-Dashboard zeigt Ransomware Resilience unterstützte und nicht unterstützte Systemkonfigurationen an. Ransomware Resilience bewertet Dateifreigaben und Blockspeicher.


NOTE: Ransomware Resilience erkennt keine Systeme mit Volumes, die FlexGroup verwenden.

Ransomware Resilience prüft Ihren aktuellen Backup-Schutz, Snapshot-Kopien und NetApp Autonomous Ransomware Protection Optionen. Ransomware Resilience erkennt außerdem Schutzinformationen von NetApp Backup and Recovery für Dateifreigaben und VM-Dateifreigaben. Anschließend empfiehlt es Möglichkeiten zur Verbesserung Ihres Ransomware-Schutzes.

*Erforderliche Konsolenrolle* Um diese Aufgabe auszuführen, benötigen Sie die link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-platform-roles.html#super-admin-roles["Super-Admin"^] oder die Administratorrolle für Ransomware Resilience. link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-ransomware-roles.html["Erfahren Sie mehr über Ransomware Resilience-Rollen für die NetApp Console"^].



[[select-workloads-to-discover]]
== Wählen Sie die Workloads aus, die Sie entdecken möchten

Innerhalb jedes Console-Agenten werden die Systeme ausgewählt, auf denen Workloads erkannt werden sollen.

Die Erkennung von Workloads schützt diese nicht automatisch. Ransomware Resilience erkennt bestehende Schutzrichtlinien von NetApp Backup and Recovery oder ONTAP während des Erkennungsprozesses. Für alle Workloads ohne Schutz müssen Sie link:rp-use-protect.html["Schutz konfigurieren"].


NOTE: Ransomware Resilience kann nur bis zu 3.000 Workloads pro Console agent erkennen.

.Schritte
. Wählen Sie in der NetApp Console*Schutz* > *Ransomware-Resilienz*.
+
Wenn Sie sich zum ersten Mal anmelden, wird die Startseite angezeigt. Um die kostenlose Testphase zu starten, wählen Sie *30 Tage kostenlos testen*. Wenn Sie die Testphase bereits aktiviert haben, wählen Sie *Mit der Ermittlung von Workloads beginnen*.

+
image:screen-landing.png["Screenshot der Zielseite für Ransomware Resilience"]

+
Ransomware Resilience findet sowohl unterstützte als auch nicht unterstützte Systeme.  Dieser Vorgang kann einige Minuten dauern.

. Um Systeme für einen bestimmten Console-Agenten zu ermitteln, wählen Sie den Abwärtspfeil für den Console-Agenten, der das zu ermittelnde System enthält.
+
image:screen-discover-workloads.png["Screenshot „Workloads ermitteln“"]

. Wählen Sie die Systeme aus, auf denen Sie die Erkennung durchführen möchten.
. Wählen Sie *Entdecken*.
+
Ransomware Resilience ermittelt Workload-Daten nur für die von Ihnen ausgewählten Systeme. Der Ermittlungsprozess kann einige Minuten dauern.

. Um die Liste der erkannten Workloads herunterzuladen, wählen Sie *Ergebnisse herunterladen*.
. Um das Ransomware Resilience-Dashboard anzuzeigen, wählen Sie *Zum Dashboard gehen*.
+
Das Dashboard zeigt den Status des Datenschutzes an. Die Anzahl der gefährdeten oder geschützten Workloads wird aktualisiert, wenn neue Workloads erkannt werden.

+
image:screen-dashboard.png["Ransomware Resilience Dashboard"]

+
link:rp-use-dashboard.html["Erfahren Sie, was das Dashboard Ihnen anzeigt."]





[[discover-newly-created-workloads-for-previously-selected-systems]]
== Entdecken Sie neu erstellte Workloads für zuvor ausgewählte Systeme

Wenn Sie einem zuvor erkannten System Workloads hinzugefügt haben, sollte die Erkennung erneut ausgeführt werden, damit die neuen Workloads identifiziert und geschützt werden.

.Schritte
. Um den Zeitpunkt der letzten Erkennung zu ermitteln, sehen Sie sich den Datums- und Zeitstempel neben dem Symbol *Aktualisieren* oben rechts im Ransomware-Resilienz-Dashboard an.
. Wählen Sie im Dashboard das Symbol *Aktualisieren*, um neue Workloads zu identifizieren.



TIP: Falls Sie feststellen, dass für das von Ihnen ermittelte System keine Volumes angezeigt werden, werden diese Volumes möglicherweise nicht unterstützt. Um eine Liste der nicht unterstützten Volumes zu finden, gehen Sie zum Menü **Einstellungen** und wählen Sie dann das Aktionsmenü in der Workload-Erkennungskarte aus, um einen JSON-Bericht über unterstützte und nicht unterstützte Volumes herunterzuladen.



[[discover-new-systems]]
== Entdecken Sie neue Systeme

Wenn bereits eine Erkennung auf einem System durchgeführt wurde und später eine Arbeitslast hinzugefügt wurde, sollte die Erkennung erneut durchgeführt werden, um diese zu identifizieren.

.Schritte
. Wählen Sie in NetApp Ransomware Resilience *Einstellungen* aus.
. Wählen Sie in der Workload-Erkennungskarte *Erkennen* aus. Die Erkennung kann einige Minuten dauern. Ein Ladesymbol zeigt den Fortschritt an.
. Ransomware Resilience erkennt sowohl unterstützte als auch nicht unterstützte Systeme. Systeme mit einer ONTAP Version unterhalb der erforderlichen Version werden nicht unterstützt. Beim Überfahren eines nicht unterstützten Systems mit dem Mauszeiger wird der Grund in einer Kurzbeschreibung angezeigt. Wählen Sie die Systeme aus, auf denen Sie Workloads identifizieren möchten.
. Wählen Sie *Entdecken*.




[[exclude-workloads]]
== Arbeitslasten ausschließen

Ransomware Resilience ermöglicht das Ausschließen bestimmter Workloads in einem System vom Ransomware-Schutz und der Erkennung.

Sie können nur solche Workloads ausschließen, die unterstützt werden und erfolgreich erkannt wurden. Sie können die Liste der ausgeschlossenen Workloads jederzeit ändern. Für Workloads, die von der Ransomware-Resilienz ausgeschlossen sind, werden keine Gebühren erhoben.

.Fügen Sie Arbeitslasten zur Liste der ausgeschlossenen Arbeitslasten hinzu
. Unter Ransomware Resilience wählen Sie **Einstellungen**.
. Suchen Sie im Dashboard „Einstellungen“ das Dashboard „Workload-Erkennung“. Die Karte gibt die Anzahl der ausgeschlossenen Workloads an. Um Workloads hinzuzufügen, wählen Sie neben den ausgeschlossenen Workloads die Option **Verwalten**.
+
image:settings-excluded-workload.png["Dashboard für die Einstellungen zur Ransomware-Resilienz"]

. Wählen Sie auf der Seite „Ausgeschlossene Workloads“ die Option **Hinzufügen**.
. Wählen Sie die Workloads aus, die Sie ausschließen möchten, und klicken Sie dann auf **Hinzufügen**.
. Überprüfen Sie die ausgeschlossenen Workloads auf der Seite „Ausgeschlossene Workloads“. Während die Arbeitslast hinzugefügt wird, wird neben ihrem Namen eine Fortschrittsanzeige angezeigt. Wenn eine Arbeitslast nicht erfolgreich ausgeschlossen wurde, wird sie nicht auf der Seite angezeigt.


.Workloads aus der Liste der ausgeschlossenen Workloads entfernen
. Unter Ransomware Resilience wählen Sie **Einstellungen**.
. Suchen Sie im Dashboard „Einstellungen“ das Dashboard „Workload-Erkennung“. Die Karte gibt die Anzahl der ausgeschlossenen Workloads an. Wählen Sie neben den ausgeschlossenen Workloads **Verwalten** aus.
+
image:settings-excluded-workload.png["Screenshot des Dashboards mit den Einstellungen zur Ransomware-Resilienz."]

. Um eine einzelne Arbeitslast zu entfernen, wählen Sie im Aktionsmenü die Arbeitslast aus, die Sie aus der Ausschlussliste entfernen möchten.
+
Um mehrere Workloads zu entfernen, wählen Sie das Kontrollkästchen neben den Workloads aus, die Sie entfernen möchten, und klicken Sie dann auf **Aus ausgeschlossenen entfernen**.

. Wählen Sie im Dialogfeld **Entfernen**, um zu bestätigen, dass Sie die Workloads aus der Ausschlussliste entfernen möchten.
. Wenn die Arbeitslast erfolgreich aus der Liste der ausgeschlossenen Arbeitslasten entfernt wird, erscheint eine Erfolgsmeldung auf der Seite „Ausgeschlossene Arbeitslasten“ und die Arbeitslast erscheint nicht mehr in der Liste der ausgeschlossenen Arbeitslasten. Schlägt die Aktion fehl, erscheint eine Fehlermeldung; der Vorgang kann erneut versucht werden. image:exclude-workload-remove-successful.png["Screenshot der erfolgreichen Entfernung einer ausgeschlossenen Arbeitslast."]
