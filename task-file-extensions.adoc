= Blockierte oder zulässige Dateierweiterungen in NetApp Ransomware Resilience managen
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
NetApp Ransomware Resilience unterstützt die Konfiguration einer Schutzstrategie, die verdächtige Dateierweiterungen blockiert. Ransomware Resilience stellt standardmäßig eine Liste bekannter verdächtiger Dateierweiterungen bereit, die blockiert werden, um Ransomware-Angriffe zu verhindern. Sie können die Liste der Dateierweiterungen anpassen und Einträge nach Bedarf hinzufügen oder entfernen.

Wenn der Schutz mit der Blockierung verdächtiger Dateierweiterungen konfiguriert wird, erfolgt dies auf Workload-Ebene. Es ist jedoch möglich, festzulegen, welche Dateierweiterungen auf Ebene der Storage VM (SVM) blockiert werden, sodass verschiedene SVMs innerhalb desselben Workloads unterschiedliche Listen verwenden können.



[[how-file-extension-blocking-works]]
== Wie die Blockierung von Dateierweiterungen funktioniert

Es gibt zwei Ansätze zum Konfigurieren von Dateierweiterungslisten:

* *Dateierweiterungen blockieren* - Alle in der Liste enthaltenen Dateierweiterungen werden blockiert und als Ransomware-Bedrohungen markiert.
* *Dateierweiterungen zulassen* - Nur Dateien mit Erweiterungen aus dieser Liste sind erlaubt. Jede Datei mit einer nicht in der Liste aufgeführten Erweiterung wird blockiert und als Ransomware-Bedrohung eingestuft.




[[file-extension-blocking-from-ontap]]
=== Blockierung von Dateierweiterungen durch ONTAP

Wenn Sie in ONTAP bestimmte Dateierweiterungen zum Blockieren festgelegt haben, erkennt Ransomware Resilience diese Einstellungen. Wenn Sie link:rp-use-protect.html["Schutz konfigurieren"] in Ransomware Resilience so konfigurieren, dass verdächtige Dateierweiterungen blockiert werden, verwendet Ransomware Resilience standardmäßig eine sorgfältig zusammengestellte Liste von Dateierweiterungen, sofern Sie keine andere Standardeinstellung konfiguriert haben.



[[default-file-extensions]]
=== Standarddateierweiterungen

Ransomware Resilience stellt eine Standardliste blockierter Dateierweiterungen bereit, die „NetApp“ genannt wird. Standardmäßig verwenden alle Workloads, die für das Blockieren verdächtiger Dateierweiterungen aktiviert sind, diese Liste, die mehr als 3.900 bekannte schädliche Dateierweiterungen enthält. Sie können diese Liste ändern oder sie kopieren, um sie als Grundlage für eine benutzerdefinierte Liste zu verwenden.

Sie können eine andere Liste als Standard festlegen. Sobald eine Liste als Standard festgelegt ist, verwenden alle Workloads, für die anschließend die Dateiblockierung aktiviert wird, diese Liste, sofern Sie nicht manuell eine andere Liste auswählen.



[[create-a-file-extensions-list]]
== Erstellung einer Liste der Dateierweiterungen

.Schritte
. Unter Ransomware Resilience wählen Sie **Einstellungen**.
. Unter der Überschrift „Dateierweiterungen“ wird **Managen** ausgewählt.
. Wählen Sie **Hinzufügen**.
. Geben Sie einen *Namen* für die Liste an.
. Auswahl der Funktionsweise der Liste:
+
** Die Auswahl von *Erweiterungen blockieren* kennzeichnet alle Dateierweiterungen in der Liste automatisch als Ransomware-Bedrohung.
** Bei Auswahl von *Erweiterungen zulassen* sind nur Anfragen von Dateierweiterungen in der Liste zulässig.


. Wählen Sie aus, wie die Liste erstellt werden soll:
+
** Zum Erstellen auf Basis einer bestehenden Liste steht die Registerkarte *Liste kopieren* zur Verfügung.
+
Die Liste der Dateierweiterungen kann überprüft werden. Zum Löschen von Erweiterungen ist das „X“ neben dem Dateierweiterungstyp zu wählen. Mit *+ Zur Liste hinzufügen* lassen sich zusätzliche Erweiterungen hinzufügen; diese Auswahl führt zur Registerkarte *Manuell eingeben*.

** Die Registerkarte *Hochladen* dient zum Hinzufügen einer Liste von Dateierweiterungen aus einer CSV-Datei.
+
Nach der Auswahl von *Upload* erfolgt die Auswahl einer CSV-Datei, die die Liste der Dateierweiterungen enthält, die Sie blockieren oder zulassen möchten.

** Für die Eingabe der Liste ist *Manuell eingeben* auszuwählen. Die Liste ist als eine Reihe von durch Kommas getrennten Werten einzugeben, zum Beispiel "vvv, xyz, zzz".


. Nach der Überprüfung der Liste der Dateierweiterungen erfolgt die Auswahl von *Hinzufügen*, um die neue Liste zu erstellen.
+
image:blocked-file-extensions.png["Screenshot der blockierten Dateierweiterungen."]





[[apply-a-file-extension-list-to-an-svm]]
[[svm]]
== Anwenden einer Dateierweiterungsliste auf eine SVM

Wenn Sie eine Ransomware-Schutzstrategie mit der Richtlinie zum Blockieren verdächtiger Dateierweiterungen zuweisen, können Sie eine spezifische Liste von Dateierweiterungen für die gesamte Workload festlegen. Nach Anwendung der Datensicherungsstrategie können Sie verschiedenen SVMs unterschiedliche Listen zuweisen.

Die Arbeitslast muss eine Erkennungsrichtlinie enthalten, die verdächtige Dateierweiterungen blockiert, bevor Sie diese Aufgabe ausführen können. Informationen dazu, wie link:rp-use-protect.html["Konfiguration einer Ransomware-Schutzstrategie"]. Sie können jeder SVM nur eine Liste von Dateierweiterungen zuweisen.

.Schritte
. Unter Ransomware Resilience wählen Sie **Einstellungen**.
. Unter der Überschrift „Dateierweiterungen“ wird **Managen** ausgewählt.
. Die Registerkarte *Storage VM* ist auszuwählen.
. Die Liste der SVMs mit aktiviertem Schutz vor verdächtigen Dateierweiterungen ist hier aufgeführt. Es ist erkennbar, welche SVM welche Liste verwendet. Für Änderungen an der Liste steht *Liste ändern* zur Verfügung.
. Im Dialogfeld erfolgt zunächst die Auswahl der neuen Liste aus dem Dropdown-Menü, danach die Auswahl von *Speichern*.




[[manage-file-extension-lists]]
== Dateierweiterungslisten managen

Sie können den Inhalt der Dateierweiterungsliste jederzeit ändern. Sie können eine Liste löschen oder eine Liste als Standardliste festlegen, die beim Aktivieren der Blockierung verdächtiger Dateien verwendet wird.

.Eine Dateierweiterungsliste ändern
. Unter Ransomware Resilience wählen Sie **Einstellungen**.
. Unter der Überschrift „Dateierweiterungen“ wird **Managen** ausgewählt.
. Sie können die Dateierweiterungsliste auswählen, die geändert werden soll.
. Das Hinzufügen von Dateierweiterungen zur Liste erfolgt über das Aktionsmenü und anschließend über *Dateierweiterungen hinzufügen*.
+
.. Die Registerkarte für die Methode, mit der die Liste geändert werden soll, ist auszuwählen. Für den Import einer vorhandenen Liste ist *Liste kopieren* auszuwählen, für den Import von Dateierweiterungen aus einer CSV-Datei *Hochladen* und für die manuelle Übermittlung von Dateierweiterungen *Manuell eingeben*.
.. Mit *Hinzufügen* werden die Änderungen gespeichert.


. Zum Entfernen von Dateierweiterungen erfolgt im Menü „Dateierweiterungen“ die Auswahl des Namens der Liste, die geändert werden soll.
+
.. In der Liste der Dateierweiterungen ist das Kontrollkästchen neben jeder Dateierweiterung auszuwählen, die entfernt werden soll. Oben in der Liste ist **Entfernen** auszuwählen.
+
Alternativ erfolgt das Entfernen für die jeweilige Dateierweiterung über das Aktionsmenü am Ende der Zeile und anschließend über *Entfernen*.



. Mit *Speichern* lässt sich die Liste ändern.


.Festlegen einer Dateierweiterungsliste als Standard
. Unter Ransomware Resilience wählen Sie **Einstellungen**.
. Unter der Überschrift „Dateierweiterungen“ wird **Managen** ausgewählt.
. Im Aktionsmenü der Liste, die als Standardliste festgelegt werden soll, wird die Option *Als Standardliste markieren* gewählt.
. Die Liste wird anschließend als Standard festgelegt. Workloads, die durch die Liste blockierter Dateierweiterungen geschützt sind und keiner spezifischen Liste zugeordnet wurden, blockieren oder erlauben Dateierweiterungen basierend auf dem neuen Standard.


.Löschen einer Dateierweiterungsliste
Eine Liste, die auf eine SVM angewendet wird, kann nicht gelöscht werden. Zuerst muss <<svm,Änderung der mit der SVM verknüpften Liste>>.

Die NetApp Liste kann nicht gelöscht werden.

. Unter Ransomware Resilience wählen Sie **Einstellungen**.
. Unter der Überschrift „Dateierweiterungen“ wird **Managen** ausgewählt.
. Anschließend erfolgt im Aktionsmenü der zu löschenden Liste die Auswahl von *Liste löschen*.
. Die Löschung wird im Dialogfeld bestätigt.
